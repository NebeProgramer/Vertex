# Vertex 1.3.1 está aquí
Ahora cada ventana de algoritmo trae su propia clase particular: aprende cómo funciona el método que estás usando sin salir de Vertex ni buscar en otro lado.

---

## 🚀 Nuevas funciones

### 📘 Ayuda teórica por algoritmo
El botón **(?)** de la barra de título de cada ventana de resultados (Simplex, Big M, Simplex Dual, Costos Duales, Gráfico, Húngaro y Numérico) ahora es clicable. Al presionarlo se abre una subventana con una explicación completa de ese método: qué problema resuelve, su fundamento matemático, el ciclo del algoritmo paso a paso y un ejemplo numérico resuelto de principio a fin — con letra grande y clara, pensada para leerse cómodo. El tooltip que ya conocías sigue apareciendo al pasar el mouse, para cuando solo necesitas el recordatorio rápido de colores.

## 📦 Descarga
Esta release trae dos formas de obtener Vertex, elige la que prefieras:

- **Instalador (`VertexSetup.msi`):** la opción recomendada. Lo instala en tu equipo con acceso directo y desinstalador incluido.
- **Portátil (`Vertex.zip`):** descomprime y ejecuta `Vertex.jar` (o `java -jar Vertex.jar`) sin necesidad de instalar nada. Útil si no tienes permisos de administrador.
