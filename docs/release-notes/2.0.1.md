# Vertex 2.0.1: arreglo de bugs
Esta versión corrige un problema detectado en la 2.0.0: los números no se veían igual en todas las ventanas de resultados. Sin cambios en las funciones existentes.

---

## 🐛 Bugs corregidos

- **Formato numérico distinto en cada ventana de resultados** (`n_000010`): según el algoritmo, un mismo valor aparecía como `60`, `60.000` o `60,00`, con coma o con punto según el idioma del equipo. Ahora las 7 ventanas (tablas, solución, gráfica y cuadros flotantes) usan el mismo formato:
  - punto como separador decimal, siempre;
  - 3 decimales (`2.500`, `0.333`);
  - los enteros sin decimales (`60`, no `60.000`).

---

## 📦 Descarga
Esta release trae dos formas de obtener Vertex, elige la que prefieras:

- **Instalador (`VertexSetup.msi`):** la opción recomendada. Lo instala en tu equipo con acceso directo y desinstalador incluido.
- **Portátil (`Vertex.zip`):** descomprime y ejecuta `Vertex.jar` (o `java -jar Vertex.jar`) sin necesidad de instalar nada. Útil si no tienes permisos de administrador.
