# Vertex 1.3 está aquí
Ahora Vertex se puede instalar como cualquier otro programa de Windows, con su propio instalador — sin perder la opción portátil de siempre.

---

## 🚀 Nuevas funciones

### 💿 Instalador para Windows
Vertex ya tiene su propio instalador `.msi`: elige dónde instalarlo, queda con acceso directo en el menú de inicio y con el ícono de Vertex en cada paso, y se puede desinstalar desde el Panel de Control como cualquier otro programa.

### 🗂️ Historial persistente entre instalaciones
El historial de cálculos ya no se guarda junto al programa, sino en una carpeta propia del usuario. Esto significa que instalar una nueva versión de Vertex (o reinstalarlo) **ya no borra tu historial** — y si vienes de una versión anterior, tu historial existente se conserva automáticamente la primera vez que abras esta versión.

## 📦 Descarga
Esta release trae dos formas de obtener Vertex, elige la que prefieras:

- **Instalador (`VertexSetup.msi`):** la opción recomendada. Lo instala en tu equipo con acceso directo y desinstalador incluido.
- **Portátil (`Vertex.zip`):** descomprime y ejecuta `Vertex.jar` (o `java -jar Vertex.jar`) sin necesidad de instalar nada. Útil si no tienes permisos de administrador.
